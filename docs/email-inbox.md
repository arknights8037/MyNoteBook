# 邮箱连接器与收件箱

> 状态（实现于 2026-07-28）：首个可用版本支持标准 IMAP over TLS 的账户验证、凭据保护、手动只读同步、本地邮件列表、纯文本详情和本地处理状态。OAuth、后台轮询、发送与远端写操作尚未实现。

## 1. 用户入口

- “连接与扩展 → 连接器”负责添加、同步和删除邮箱账户；
- “收件箱 → 邮件”负责阅读邮件；
- “收件箱 → 待处理”展示本地仍为 `pending` 的邮件；
- “收件箱 → 全部动态”将已同步邮件与 RSS 按来源时间合并；IM 信号后续接入。

## 2. 安全边界

- 只允许 TLS IMAP 连接；当前不提供明文 IMAP。
- 邮箱密码或应用专用密码使用现有 OS 凭据保护的数据密钥加密保存，不进入 SQLite。
- SQLite 只保存账户非敏感配置、同步状态和邮件的本地只读副本。
- 服务端邮箱通过 `EXAMINE` 只读打开，正文使用 `BODY.PEEK` 获取，不改变服务器已读状态。
- 登录后会检查服务器 `CAPABILITY`；当服务器声明 RFC 2971 `ID` 能力时，客户端会先发送 MyNoteBook 的名称、版本、厂商和支持地址，再打开邮箱。该流程兼容网易系邮箱的客户端身份检查。
- 首版不发送、回复、删除、移动邮件，也不修改服务端 Flag。
- 邮件 HTML 不直接渲染；详情只展示解析后的纯文本，避免远程图片、脚本和跟踪像素。

## 3. 同步限制

- 单次同步最多读取最近 50 封，界面默认 25 封；
- 单封最多请求 1 MiB 原始内容；
- 本地正文最多保存 200,000 个字符；
- 附件只记录数量，不保存附件内容；
- 同步为用户手动触发，不在应用关闭后运行。

这些限制用于控制内存、磁盘和不可信 MIME 内容的影响，后续应在增量 UID/UIDVALIDITY 模型完成后再扩大范围。

## 4. 本地处理状态

`email_messages.processing_status` 只影响 MyNoteBook：

- `pending`：待处理；
- `done`：已处理；
- `archived`：本地归档。

它与 IMAP `\Seen`、`\Answered`、`\Deleted` 等服务器 Flag 分离，重新同步不会覆盖本地处理状态。

## 5. 当前认证范围

首版支持服务器允许的密码或应用专用密码登录。部分大型邮件服务已经限制普通密码 IMAP，因此 Gmail、Outlook 等账户的完整接入仍需 OAuth 2.0：

1. 浏览器授权与回调；
2. access/refresh token 安全保存；
3. token 刷新、撤销和权限说明；
4. IMAP XOAUTH2 或服务商 API 适配。

在 OAuth 完成前，界面必须明确说明限制，不能将普通密码失败描述为邮箱不可用。

## 6. 网易系邮箱与 Unsafe Login

163、126、yeah.net、188 等网易系邮箱可能要求第三方客户端在登录后发送 RFC 2971 IMAP `ID` 信息，否则返回 `Unsafe Login`。MyNoteBook 会在服务器明确支持 `ID` 扩展时自动发送：

- `name`：MyNoteBook；
- `version`：当前应用包版本；
- `vendor`：MyNoteBook Project；
- `support-url`：项目 GitHub 地址。

这不会替代邮箱服务商自身的安全设置。用户仍需在邮箱后台开启 IMAP 服务，并使用服务商生成的授权码；若服务器在认证阶段直接拒绝登录，应按错误提示检查授权码或联系邮箱服务商。
