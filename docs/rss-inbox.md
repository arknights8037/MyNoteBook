# RSS 连接器与收件箱

> 状态（实现于 2026-07-28）：支持 RSS 0.x/1.0/2.0、Atom 和 JSON Feed 的添加验证、手动条件同步、文章页正文提取、本地去重、纯文本阅读和本地处理状态。

## 1. 用户入口

- “连接与扩展 → 连接器”负责添加、同步、打开站点和删除订阅源；
- “收件箱 → RSS”负责按订阅源阅读条目；
- “收件箱 → 待处理 / 全部动态”将 RSS 与邮件按来源时间合并；
- Feed 只有标题或摘要时，同步会自动跟随条目链接提取最近文章的可读正文；详情页可单条重试或重新提取；
- “打开原文”仍必须由用户点击，阅读界面不会嵌入或执行源站页面。

## 2. 抓取与安全边界

- 只支持公共 `http://` 和 `https://` 地址；拒绝 URL 凭据、本机、私有网络、链路本地和保留地址；
- DNS 结果在发起请求前校验并固定到本次请求，重定向逐跳重新校验，最多 5 次；
- 连接超时 10 秒、总请求超时 25 秒，单个 Feed 响应最多 2 MiB；
- 文章页同样经过公网地址与逐跳重定向校验，单页最多 4 MiB；自动提取每次最多 12 篇、每批并发 4 篇；
- 每次最多解析 100 条，界面默认读取最近 50 条；
- Feed 中的 HTML 会转换为纯文本，脚本、样式、远程图片和跟踪像素不会进入阅读界面；
- 文章页使用 Readability 规则抽取主体，只保存最多 100,000 字符的纯文本；提取失败时保留原摘要且不阻断同步；
- 条目正文最多保存 100,000 个字符，摘要最多 320 个字符。

这些限制意味着首版不支持局域网、自托管内网 Feed。若以后开放，应作为显式的高级信任选项，而不是放宽默认策略。

## 3. 增量与去重

- 保存服务器返回的 `ETag` 和 `Last-Modified`；
- 后续同步发送 `If-None-Match` 和 `If-Modified-Since`；
- `304 Not Modified` 只更新时间，不重复解析或写入；
- 升级前已经落库且尚未尝试全文提取的摘要，会在下一次同步时主动刷新一次 Feed 完成正文回填；
- 条目使用规范 ID、文章地址或标题/时间/作者组合生成 SHA-256 稳定标识；
- SQLite 以 `(source_id, remote_id)` 唯一约束去重，内容更新不会覆盖本地处理状态。

## 4. 本地处理状态

`rss_entries.processing_status` 仅影响 MyNoteBook：

- `pending`：待阅读或待跟进；
- `done`：已处理；
- `archived`：本地归档。

这些状态不会请求或修改 RSS 源站。

## 5. 当前限制

- 仅支持手动同步，没有后台轮询；
- 未实现 OPML 批量导入/导出；
- 依赖客户端脚本渲染、登录墙或主动反爬的页面可能无法提取，此时保留 Feed 摘要并显示失败原因；
- 未下载播客或其他 enclosure；
- 未将 RSS 摘要投影到信息面板 Widget。
